# Rendez — UI Design Screens

Tổng số: 83 hình thiết kế riêng (75 mobile + 8 desktop), 8 bảng tổng hợp, 1 concept image tham khảo.

Mỗi frame 900 × 1920 px, tương ứng mockup 450 × 960 logical pixels. Đây là visual specification đề xuất, không phải ảnh chụp Flutter runtime hoặc pixel-perfect xuất từ Figma.

Các hình dùng dữ liệu ví dụ minh họa. Mã ID và tên màn hình nằm trong MANIFEST.json.

Đối chiếu luồng chính với repository longqt321/Rendez; các trạng thái H và một số hộp thoại là thiết kế bổ sung.
